# Alfa Test Helper — 1.2.0 (пробная версия)

Расширение Chrome / Edge для Alfa People: поиск ответов в QTI XML,
подсветка вариантов и экспериментальное автопрохождение.

## Установка

1. Распакуйте архив в постоянную папку.
2. Откройте `chrome://extensions` (Edge: `edge://extensions`).
3. Включите режим разработчика, выберите «Загрузить распакованное расширение».
4. Выберите папку с `manifest.json`, перезагрузите страницу обучения.

Обновление: замените файлы в установленной папке, обновите расширение на
странице расширений и перезагрузите сайт. Папку после установки не удаляйте.

## Работа

Ответы из `response_label[ws_right="1"]` появляются в панели справа.
Совпадающие варианты текущего вопроса выделяются зелёным и подчёркиваются.

Внизу справа находится панель автопрохождения. Нажмите «Запустить»:

- выбираются все однозначно сопоставленные ответы из XML;
- снимаются лишние отметки в вопросах с несколькими ответами;
- нажимаются доступные «Ответить», «Отправить», «Проверить»;
- раскрываются стандартные `details` и кнопки с `aria-expanded="false"` вне меню;
- нажимаются однозначные «Продолжить», «Далее», «Следующий вопрос»;
- запускается курс при единственной кнопке «Начать» и выполняется переход
  «К следующей задаче», если кнопок запуска курса не найдено.

Автопрохождение отправляет ответы и меняет прогресс обучения.
«Стоп» останавливает дальнейшие действия. Esc работает в основном документе.
Для последующих посещений можно включить «Автозапуск при открытии сайта».
Он применяется к новым вкладкам; состояние уже открытой вкладки сохраняется
до её закрытия. Отключение автозапуска не заменяет кнопку «Стоп».
Фоновые вкладки не прокликиваются. При открытии курса в новой вкладке
нужен отдельный запуск, если автозапуск выключен.

Между действиями — не менее 1,6 секунды. Фреймы одной вкладки используют
общую очередь. При повторении того же шага работа останавливается.
Если доступного шага нет 30 секунд, появляется причина остановки.

## Проверки и ограничения

Подготовленные тесты на локальных HTML-примерах проверяют выбор одного и нескольких ответов,
неизвестные вопросы, неоднозначные варианты, раскрытие блоков,
недоступные кнопки, экран обратной связи и координацию фреймов.
Реальный закрытый сайт не был доступен из среды разработки. Совместимость
с его фактическими HTML-компонентами пока не подтверждена.
Локально прошёл тест координации фреймов. Браузерные тесты локально
не запустились из-за запрета запуска процесса Chrome (EPERM).
Для повторяемой проверки добавлен GitHub Actions workflow.

На скриншотах видны разные типы обучения. Метки правильности после ответа
не доказывают наличие QTI XML у встроенного упражнения. Если XML нет,
расширение не угадывает ответы. Такие упражнения требуют отдельного адаптера
после изучения разметки. Не поддержаны перетаскивание, сортировка, видео,
таймеры, ответы изображениями, закрытые Shadow DOM и фреймы иных доменов.
Стрелка без подписи и нестандартный аккордеон могут не распознаться.

## Данные и разрешения

Работает только на `https://alfapeople.alfabank.ru/`. Ответы обрабатываются
в памяти страницы. Внешних сервисов, аналитики и отправки XML нет.
Перехватываются ответы fetch/XHR с путём `/qti`; для восстановления данных
может повторяться последний запрос к тому же адресу с текущей сессией.
Разрешение `storage` хранит настройку автозапуска и состояние вкладки.
Реальные XML, ответы курсов и скриншоты в репозиторий не включаются.

## Тесты

Установите Node.js и Playwright в среду разработки, затем выполните:

```sh
npm install --no-save playwright
node --test tests/*.test.cjs
```

Тесты запускают отдельный Chrome в headless-режиме с локальными HTML-примерами,
без доступа к рабочей сессии сайта. Для Edge задайте `TEST_BROWSER=msedge`.
