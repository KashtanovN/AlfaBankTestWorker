# Alfa Test Helper — 1.3.3

## Установка и запуск
1. Распакуйте архив в постоянную папку.
2. На chrome://extensions включите режим разработчика и загрузите папку с manifest.json.
3. При обновлении замените файлы, обновите расширение и перезагрузите сайт.
4. Самостоятельно выберите нужный курс и нажмите «Начать».
5. Внутри курса, по адресу /wshcm-player/…, нажмите «Запустить» в панели расширения.

## Только выбранный курс
Расширение запоминает course_id и object_id выбранного курса для текущей вкладки.
Выход из плеера или переход к другому курсу останавливает автоматизацию.
Каталог, боковое меню задач, кнопки «Начать» и «К следующей задаче» не прокликиваются.
Глобальный автозапуск удалён. Состояние версии 1.2 сбрасывается при обновлении.
Повторное открытие вкладки требует запуска. На фоне автоматизация не работает.
«Стоп» останавливает действия, Esc работает в основном документе.

## Поддержка
- Ответы из QTI XML с ws_right="1": подсветка, выбор и отправка.
- «Продолжить», «Продолжить →», «Далее», «Следующий вопрос».
- Стандартные details, элементы aria-expanded и вкладки role=tab внутри курса.
- Обычные HTML-video: перемотка к последней секунде и воспроизведение до окончания.
- Если браузер запрещает запуск видео, нажмите Play вручную и снова «Запустить».
- При неизвестном шаге или остановившемся видео — остановка через 30 секунд.

## Ограничения
Версия 1.3.3 перематывает обычное видео к последней секунде, когда длительность
известна и конец доступен для перемотки, затем воспроизводит остаток.
Если перемотка недоступна, видео продолжает воспроизводиться обычным способом.
При обнаруженном откате позиции плеером показывается причина остановки.
Просмотр может не засчитаться, если платформа требует воспроизведения целиком.
Совместимость с реальной разметкой закрытого сайта пока не проверена.
Произвольные интерактивные карточки, сторонние видеоплееры, фреймы другого домена,
перетаскивание, сортировка и вопросы без QTI требуют отдельной доработки.
Если тест открывается как отдельный курс с другими идентификаторами, запустите его отдельно.
Расширение не определяет статус завершения по каталогу: оно вообще не запускает курсы из каталога.
Нажатие «Запустить» внутри ранее пройденного курса считается вашим явным выбором этого курса.

## Данные
Работает только на alfapeople.alfabank.ru. XML обрабатывается локально в памяти страницы.
Внешних сервисов и аналитики нет. Разрешение storage хранит состояние текущей вкладки.
Перехватываются fetch/XHR /qti; возможен повтор последнего запроса /qti в текущей сессии.
Автоматизация действительно отправляет выбранные ответы на сайт.

## Проверки
node --test tests/*.test.cjs
Браузерным тестам нужен Playwright (1.62.1) и Chrome; TEST_BROWSER=chromium использует bundled Chromium.
В GitHub Actions тесты запускаются на локальных искусственных HTML-примерах, без доступа к сайту банка.

## Карусели в версии 1.3.3
Поддержаны кнопки Next slide с маркером sliderElNav и activeIndex в data-qa-data.
Расширение листает каждую карусель до отключения стрелки или возврата к уже просмотренному слайду. Если номер слайда не меняется, повторных кликов нет и выполнение остановится по тайм-ауту.
Адаптер сделан по разметке на скриншоте. Проверки на реальном сайте ещё не проведены.

## Приоритет перехода в версии 1.3.3
На экране с видео доступная кнопка Продолжить имеет приоритет перед перемоткой и ожиданием окончания. Пока она отключена, сохраняется прежняя обработка видео. Проверяется disabled и aria-disabled, цвет кнопки не используется.
